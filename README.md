# 國立中央大學 NCUx 雲端課程 線上授權同意書簽署系統

一套專為國立中央大學 NCUx 課程設計的輕量級線上授權同意書填寫與行動簽署系統。

## 🌟 功能特色
- **承辦人彈性自訂**：可動態切換創用 CC 條款、活動名稱與授權人姓名，支援一鍵產生專屬帶入參數連結與 QR Code。
- **行動友善手寫簽名**：支援手機防滑動觸控手寫簽名板、貝茲曲線平滑筆跡與橫向全螢幕簽署模式。
- **A4 樣張預覽與繁中 PDF 匯出**：完美解決 jsPDF 中文亂碼問題，支援高解析度 A4 套表預覽與下載。
- **防篡改數位稽核存證**：自動封裝 NTP 時間戳記、SHA-256 簽名雜湊碼與環境資訊。

## 🚀 線上展示與使用
透過 GitHub Pages 部署後，直接開啟 `https://<你的GitHub帳號>.github.io/<儲存庫名稱>/` 即可使用。
例如https://tsaidashu.github.io/ncux-signature-system/
